### Relative Markdown links

[CONTRIBUTING.md](../../../CONTRIBUTING.md) were both executed verbatim against the
tracked Markdown set. Each enumerates `git ls-files '*.md'`, drops fenced code

the file that contains it.

files and 18 resolved relative links.

An earlier revision of the check inspected fenced code blocks and reported one false
positive by matching the `](` sequence inside its own POSIX command sample. Skipping
fenced blocks removed it. The false positive is recorded here rather than discarded,
and no failed or superseded result is represented as proof.
