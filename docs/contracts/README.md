# Contracts

Status: entry point established; no public contract accepted.

This directory will index versioned, machine-readable public contracts and their
compatibility policy after those artifacts pass their own decision and evidence
gates. There is currently no supported workload schema, API contract, fixture, or
compatibility claim in this repository.

A future contract entry must identify its owner, version, maturity, compatibility
rules, valid and invalid fixtures, security behavior, telemetry implications, and
validation evidence. Proposed documents must be visibly labelled as proposed.
